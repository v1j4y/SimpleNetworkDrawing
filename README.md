# Tensor Network Figures

## Introduction

Simple figures with a special focus on abelian and
non-abelian symmetric tensors.

Focus is on simple vanilla figures without bangs and stars.

## Method

The figures are drawn using the Quimb python library.

## Details

The tensors are used to represent U(1)xZ2 and SU(2)xZ2xU(1) symmetry.
Therefore, the tensors have symmetry sectors, for e.g. for U(1)xZ2,
the tensors have charge sectors (i.e. the sectors representing the different
number of electrons) which are block diagonal.
